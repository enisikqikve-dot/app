# Weltenfunke

*(Arbeitstitel)*: Ein Lebens-Simulator im Browser, in dem du ein Gott bist.
Die Menschen leben, lieben, arbeiten, erfinden und streiten von selbst, von der
Steinzeit bis in die Zukunft. Du schaust zu und greifst ein, wann du willst.

**Status:** Konzeptphase, noch kein Code.

👉 Das vollständige Spielkonzept steht in [KONZEPT.md](KONZEPT.md).

Geplante Technik: TypeScript, Vite, Three.js (3D im Browser).
